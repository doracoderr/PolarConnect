# 🌍 PolarConnect — Bulk Content Seeding Guide

Ye guide explain karta hai kaise ~30 NCPOR expeditions + projects ko directly MongoDB me add kar sakte ho **auto-generated summaries** ke sath.

---

## **Quick Start (3 steps)**

### **1. Ensure Admin Exists**
```bash
cd server
npm run seed:admin
```

### **2. Run Seed Script**
```bash
node src/scripts/seedContent-with-summary.js
```

### **3. Check Admin Panel**
- Go to `http://localhost:5173/admin/content`
- All items show as **DRAFT** (gray badge)
- Click **"Publish"** to make live on portal

---

## **What Happens When You Seed**

### **Data Flow:**
```
seedContent-with-summary.js
    ↓
Reads: server/src/data/contentSeedData.json
    ↓
For each item:
  1. Check if already exists (skip if yes)
  2. Parse tags from CSV format
  3. Detect mediaType (image/document based on title)
  4. Call Gemini to generate:
     - description (2-3 sentences)
     - socialCaption (social media friendly)
  5. Save to MongoDB as DRAFT
    ↓
Admin panel shows all items ready to review/publish
```

---

## **Media Handling**

Each seeded item gets:
- **mediaUrl**: Placeholder image (Unsplash) OR real PDF link (for expedition reports)
- **cloudinaryPublicId**: Fake `seed/placeholder_N` (won't transform via Cloudinary)
- **mediaType**: Auto-detected:
  - Contains "Report" → `document`
  - Contains "Expedition" → `image`
  - Default → `image`

### **Upgrading Placeholders → Real Media**

Once you have real photos/PDFs:

**Option A: Re-upload via Admin Panel**
1. Go to `/admin/upload`
2. Upload real file for each expedition
3. Admin panel auto-generates summary
4. Publish

**Option B: Batch Update Database**
```javascript
// In MongoDB shell or compass:
db.contents.updateOne(
  { title: "43rd ISEA" },
  {
    $set: {
      mediaUrl: "https://real-url-to-photo.jpg",
      cloudinaryPublicId: "polarconnect/43-isea-photo"
    }
  }
)
```

## **Sample Data Format**

**contentSeedData.json:**
```json
[
  {
    "Title": "43rd Indian Scientific Expedition to Antarctica",
    "Category": "Antarctica",
    "Expedition": "43-ISEA",
    "Season": "2023-24",
    "Tags": "Antarctica, ISEA, Maitri, season-2023-24"
  },
  ...
]
```

**Result in MongoDB (after seeding):**
```javascript
{
  _id: ObjectId(...),
  title: "43rd Indian Scientific Expedition to Antarctica",
  category: "Antarctica",
  expeditionName: "43-ISEA",
  tags: ["Antarctica", "ISEA", "Maitri", "season-2023-24"],
  description: "[auto-generated by Gemini]",
  socialCaption: "[auto-generated by Gemini]",
  mediaUrl: "https://images.unsplash.com/...",
  mediaType: "image",
  cloudinaryPublicId: "seed/placeholder_1",
  uploadedBy: ObjectId(admin),
  approvedForDisplay: false,      // DRAFT
  publishedAt: Date(...),
  createdAt: Date(...),
  updatedAt: Date(...)
}
```

## **Troubleshooting**

| Issue | Fix |
|-------|-----|
| "No admin found" | Run `npm run seed:admin` first |
| Gemini API errors | Check `GEMINI_API_KEY` in `.env` — if missing, seed still works (uses template fallback) |
| "Already existed" | Items with same title won't be added twice (safe for re-runs) |
| mediaUrl broken | Unsplash links might be throttled in high-traffic labs — replace with local images |

## **Environment Variables**

Make sure `server/.env` has:
```
GEMINI_API_KEY=your-key-here         # for auto-summary
GEMINI_MODEL=gemini-flash-lite-latest
MONGO_URI=mongodb+srv://...          # your DB
JWT_SECRET=your-secret
PUBLIC_API_URL=http://localhost:5000/api  # for media viewing
```
